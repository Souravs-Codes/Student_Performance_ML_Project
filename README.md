# 🎓 Student Performance Predictor

An end-to-end **Machine Learning application** that predicts a student's **Mathematics Score** based on academic, demographic, and educational factors.

The project demonstrates a complete Machine Learning workflow, from data ingestion and preprocessing to model training, evaluation, prediction, and deployment using **Streamlit**.

The application provides an interactive interface where users can enter student information and receive a predicted Mathematics Score in real time.

---

## 📖 Overview

Student Performance Predictor is a Machine Learning regression project built using the **Student Performance Dataset**.

The goal is to predict a student's Mathematics Score using information such as:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch Type
- Test Preparation Course
- Reading Score
- Writing Score

The project follows a structured Machine Learning pipeline and uses multiple regression algorithms to identify the best-performing model.

The final trained model is integrated into a **Streamlit web application** for interactive predictions.
